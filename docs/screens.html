Pods screens

Static render of the browser client for design reference. Layout, color, type, and copy match client/src. The clock, island, and home indicator are the phone frame. Everything inside them is the app.

Phones are 390 points wide, the iPhone width Pods is built for. Tall frames grow so the whole scroll is visible. The tab bar stays fixed to the phone while a normal screen scrolls. Listen, Played, Shows, and Settings are the tabs, and a sideways swipe moves between them. The Listen screen title is Pods.

The production build keeps the library on the phone and syncs with the Mac. Follows is built and turned off. “Add one episode” and the DeepSeek API key block appear only when that on-phone library is off.

#/recent

Sync choice

The badge sits under the status bar when the phone and the Mac disagree. Dismiss hides it for the rest of the visit. This frame is the conflict, the choice with two actions.

  • Sign in: “Sign in to update episodes from the Mac.” Button “Continue with passkey”.
  • Mac unreachable: “The Mac is not reachable. Downloaded episodes still play.” Button “Try again”.
  • Waiting: “Changes on this device are waiting to sync.” Button “Sync now”. Hidden while a sync is already running, so a played-mark does not flash the badge.
  • Never synced: “This device has not synchronized with the Mac.” Button “Sync now”.
  • Rejected: “The Mac did not accept a change to {title}. {error}” Buttons “Try again” and “Discard this change”.

#/settings

Settings

This is the production phone: Mac sync and downloads, sign out, appearance, car Bluetooth when the Mac reports it, the local ad-removal note, add a feed, YouTube, then the library. The tab bar stays fixed while this page scrolls. It is drawn at the bottom of this full-height frame.

Not on this build: “Add one episode”, the DeepSeek API key, enable and disable ad removal, usage totals, learned corrections, and the diagnostic buttons. Those render only when the on-phone library is off. A conflict in the outbox is repeated here under Mac and downloads, with the same Keep and Use buttons as the Listen badge.

Appearance is saved as Dark so it matches this preview. The product default, with nothing saved, is System.
